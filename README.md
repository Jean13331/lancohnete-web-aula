# lanchonete-web-aula
*Projeto desenvolvido em aula*

## Como usar
1. Abra o arquivo `index.html` no navegador
2. Navegue pelo cardápio e promoções
3. Clique em "Pedir" para fazer seu pedido

## Arquivos
- `index.html` — Página principal
- `style.css` — Estilos do site
- `cardapio.js` — Lógica do cardápio
- `promocoes.html` — Página de promoções
